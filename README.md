# 🔐 Glassmorphism Login Page

A simple and modern **Login Page** created using HTML and CSS.

## ✨ Features

- 🪟 Glassmorphism design
- 🔐 Username and password fields
- 🎨 Modern gradient login button
- 🖱️ Hover and focus effects
- 📱 Responsive layout
- 🌄 Animated/background image

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts – Poppins

## 📸 Preview

A clean glass-style login interface with a blurred transparent card over a background image.

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
